# Proposal: 修正相册能力 spec 与代码的不一致

## Why

`album` 能力 spec 首次依据 PRD 与历史文档编写，包含若干代码里并不存在或参数不符的
描述：画布比例少了 3:4、声称支持「方向键 1px / Shift 10px 微调」与「换图」（均无
实现）、图注有无编辑入口未说明、撤销步数写 20（实际 30）、冲突选项写成「查看对方
版本 / 取消」（实际是覆盖 / 加载对方版本）。为避免误导后续开发，按代码现状修正。

## What Changes

- `相册管理`：补充封面自动取第一页第一张、`sortOrder` 排序通过 PATCH。
- `自由排版编辑器`：比例档位写全（3:2 / 4:3 / 1:1 / 3:4 / 2:3）；撤销/重做 30 步
  （Ctrl/Cmd+Z / Shift+Z）；层级操作为置顶/上移/下移/置底；图注字段可渲染但当前
  无编辑入口；**删除**未实现的「方向键微调」与「换图」；吸附为屏幕 8px 阈值、旋转
  在 90° 附近 5° 内吸附。
- `自动保存与并发冲突`：debounce 900ms；冲突面板为「用我的版本覆盖 / 放弃我的改动，
  加载对方的版本」。
- 不改代码。

## Capabilities

- **Modified Capabilities**：
  - `album` — 相册管理、自由排版编辑器、自动保存与并发冲突的描述修正

## Impact

- 修改：`openspec/specs/album/spec.md`
- 不触碰：任何 `.js` / `.html` / `.css`
